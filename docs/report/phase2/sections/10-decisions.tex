\label{sec:changed}

Several design decisions changed during Phase 2. Most changes came from building a part against what was already built. The plan was written before any Phase 2 code, and some of the values and mechanisms it named did not fit once the code existed. A few came from measurement, such as the hop limit. Tables~\ref{tab:changed} and \ref{tab:changed2} list them, with the reason for each. ``From'' is what the Phase 2 plan, the outline of Phase 2 at the end of the Phase 1 report \cite{phase1}, or the first version built said.

As in Phase 1, every decision was recorded with the options considered, the reasons for the choice and who made it, together with updated architecture diagrams, so a later change could see why the earlier choice was made. In Phase 2 six parts were built at the same time, so a change that crossed parts named every owner it touched, and the earlier decision was marked as changed rather than rewritten.
